# 🐦 Flappy Bird — Java

A simple Flappy Bird-style game built using **Java** as a practice project to improve game development, programming logic, and object-oriented programming skills.

## Features

* Bird movement with gravity and jump mechanics
* Continuously moving pipes
* Random pipe generation
* Collision detection
* Score tracking
* Game-over condition
* Restart functionality
* Simple game loop and keyboard controls

## Technologies Used

* Java
* Object-Oriented Programming
* Game Loop
* Collision Detection
* Keyboard Input
* Java Graphics

## How to Play

* Press the designated key to make the bird jump.
* Avoid hitting the pipes and ground.
* Pass through the gaps between the pipes to increase your score.
* Try to achieve the highest score possible.

## Purpose

This project was created as part of my journey to improve my **Java programming, problem-solving, game development, and OOP skills**.

It was built from scratch as a hands-on project to understand how real-time game mechanics work in Java.
